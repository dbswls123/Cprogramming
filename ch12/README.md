**실습과제 1**
16MB 메모리의 주소의 범위를 구하시오.
- 0x000000~0xFFFFFF
변수의 주소를 설명하시오.
- 메모리에 저장되어있는 변수의 위치를 나타내는 값, 컴퓨터에 의해서 자동으로 결정됩니다.
변수의 주소의 자료형은 무엇인가?
- 변수의 주소를 나타낼땐 포인터(*)를 사용합니다.
포인터란 무엇인가?
- 메모리에 저장되어있는 변수의 주소값을 저장할때 사용하는 변수
- 포인터가 어떤 변수를 가리키는지에 따라 자료형이 달라집니다.
- int형 변수를 가리키는 포인터 > int*
- char형 변수를 가리키는 포인터 > char*
- double형 변수를 가리키는 포인터 > double*
변수의 주소를 int형 변수에 저장하면 어떻게 되는가?
- 64비트 환경에서 주소는 보통 64비트인데 int는 보통 32비트이므로 주소가 잘리거나 변환될 수 있습니다.

**실습과제4**
#include <stdio.h> : 함수를 사용하기 위해 헤더파일 불러오기
int main(void) { 
	char a = 'A'; : 문자형 변수를 선언 후 변수에 A 저장
	int b = 36; : 정수형 변수를 선언 후 변수에 36 저장
	double c = 3.141592; : 실수형 변수를 선언 후 변수에 3.141592 저장
	printf("char형 변수 a의 주소 : %p\n", &a); : 주소를 출력할 때 사용하는 서식문자(%p)를 작성 후 a의 주소값인 &a를 출력하도록 작성
	printf("int 형 변수 b의 주소 : %p\n", &b); : 주소를 출력할 때 사용하는 서식문자(%p)를 작성 후 b의 주소값인 &b를 출력하도록 작성
	printf("double형 변수 c의 주소 : %p", &c); : 주소를 출력할 때 사용하는 서식문자(%p)를 작성 후 c의 주소값인 &c를 출력하도록 작성
	return 0;
}
