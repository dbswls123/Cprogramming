# 스트림과 버퍼 (Stream & Buffer)

## 1. 스트림과 버퍼의 개념

- **스트림(Stream)**: 프로그램과 입출력 장치 사이에서 데이터가 이동하는 통로
- **버퍼(Buffer)**: 프로그램과 입출력 장치 사이에서 데이터를 임시 저장하는 메모리 공간

## 2. 버퍼 사용의 장단점

### 장점
- 입출력 횟수 감소
- 운영체제 입장에서 입출력 처리 효율 향상

### 단점
- 사용자 입장에서 실제 입출력 결과를 확인하는 시간이 지연될 수 있음

## 3. 입력 버퍼에 데이터가 이미 존재할 때 `scanf()` 호출

- `scanf()` 함수는 입력 버퍼에 저장된 데이터를 먼저 읽음
- 입력 버퍼에 데이터가 남아 있다면 키보드에서 새로운 값을 입력받지 않고 기존 데이터를 읽어 처리함

## 4. 출력 버퍼의 데이터가 모니터에 출력되는 경우

- 출력 버퍼가 가득 찼을 때
- 프로그램이 정상적으로 종료될 때

## 5. 입력 과정에서의 역할 분담

1. **운영체제(OS)**: 입력 장치에서 입력 버퍼까지 데이터를 전달함
2. **`scanf()` 함수**: 입력 버퍼에 저장된 데이터를 읽음
3. **`scanf()` 함수**: 사용자가 지정한 형식에 맞게 데이터를 변환함
4. **프로그램**: 변환된 데이터를 지정된 변수에 저장하여 사용함

### 입력 과정

입력 장치 → 운영체제 → 입력 버퍼 → `scanf()` → 프로그램 변수

## 6. 출력 과정에서의 역할 분담

1. **`printf()` 함수**: 사용자가 지정한 형식에 맞게 데이터를 변환함
2. **`printf()` 함수**: 변환된 데이터를 출력 버퍼에 기록함
3. **운영체제(OS)**: 출력 버퍼의 데이터를 출력 장치로 전달함
4. **출력 장치**: 전달받은 데이터를 화면 등에 출력함

### 출력 과정

프로그램 데이터 → `printf()` → 출력 버퍼 → 운영체제 → 출력 장치

## 실행 결과가 이렇게 나오는 이유

- `scanf("%s", name)`은 이름을 입력받고, Enter를 누르면 입력 버퍼에 줄바꿈 문자(`\n`)가 남는다.
- `scanf("%c", &blood_type)`는 줄바꿈 문자도 읽으므로, 혈액형을 입력받지 않고 `\n`을 읽는다.
- 따라서 `blood_type`에 줄바꿈 문자가 저장되어 혈액형이 제대로 출력되지 않는다.

## 버퍼 상태

사용자가 `홍길동`을 입력하고 Enter를 누른 경우:

| 실행 단계 | 실행 함수 | 읽은 문자 | 읽은 후 남은 버퍼 |
|---|---|---|---|
| 1단계 | `scanf("%s", name)` | 홍길동 | `\n` |
| 2단계 | `scanf("%c", &blood_type)` | `\n` | 비어 있음 |

## 해결 방법

```c
scanf(" %c", &blood_type);
```

## 실행결과

## `scanf("%c", &ch)`의 실행 과정과 버퍼 상태

- `scanf("%c", &ch)`는 입력 버퍼에서 문자 하나를 읽는다.
- `%c`는 공백 문자나 줄바꿈 문자(`\n`)도 읽는다.
- 사용자가 `abcde`를 입력하고 Enter를 누르면 버퍼에는 `a`, `b`, `c`, `d`, `e`, `\n`이 들어간다.

### 반복문 실행 단계별 버퍼 상태

| 반복 횟수 | i | 읽은 문자 | 읽은 후 남은 버퍼 |
|---|---|---|---|
| 1회차 | 0 | a | bcde\n |
| 2회차 | 1 | b | cde\n |
| 3회차 | 2 | c | de\n |
| 4회차 | 3 | d | e\n |
| 5회차 | 4 | e | \n |

### 실행 결과

사용자가 `abcde`를 입력하고 Enter를 누르면 `scanf()`가 버퍼에서 문자를 하나씩 읽으므로 다음과 같이 출력된다.

    문자 입력: abcde
    문자: a
    문자: b
    문자: c
    문자: d
    문자: e

### 버퍼 문제 해결 방법

- `scanf("%c", &ch)`는 줄바꿈 문자도 읽기 때문에 다음 입력에 영향을 줄 수 있다.
- `scanf(" %c", &ch)`처럼 `%c` 앞에 공백을 넣으면 버퍼에 남아 있는 공백 문자와 줄바꿈 문자를 건너뛸 수 있다.
