# 실습과제 1
## 1. 함수 선언, 호출, 정의

* **함수 선언**: 함수의 형태를 미리 알림. 반환형과 매개변수 자료형을 알려줌.
* **함수 호출**: 선언된 함수를 실제로 사용함.
* **함수 정의**: 함수가 실제로 수행할 내용을 작성함.

## 2. 함수의 자료형

* **반환형과 매개변수의 자료형**으로 결정됨.
* 형식: `반환형(매개변수자료형1, 매개변수자료형2, ...)`

## 3. 함수명의 자료형

* 함수명은 **함수의 주소를 나타내며**, 함수 포인터로 사용할 수 있음.
* 형식: `반환형 (*)(매개변수자료형1, 매개변수자료형2, ...)`

## 4. void 포인터

* **모든 자료형의 주소를 저장할 수 있는 포인터**.
* `void*`는 자료형이 정해져 있지 않기 때문에 직접 간접참조할 수 없음.
* 사용하려면 **원하는 자료형으로 형변환 후 간접참조**해야 함.

## 5. 강제형변환과 자동형변환

* **강제형변환**: 프로그래머가 직접 자료형을 변환함.

  ```c
  int a = (int)3.14;
  ```

* **자동형변환**: 컴파일러가 자동으로 자료형을 변환함.

  ```c
  double a = 10;
  ```

## 설명

### 1. 함수 포인터 매개변수

```c
void calculate(int a, int b, int (*A)(int, int))
```

* `A`는 **함수 포인터**이다.
* `int`형 매개변수 2개를 받고 `int`형을 반환하는 함수를 가리킬 수 있다.

### 2. 함수 전달

```c
calculate(10, 5, Add);
calculate(10, 5, Sub);
```

* `Add`를 전달하면 `A`가 `Add` 함수를 가리킨다.
* `Sub`를 전달하면 `A`가 `Sub` 함수를 가리킨다.

### 3. 함수 포인터로 함수 호출

```c
A(a, b)
```

`A`가 가리키고 있는 함수를 호출한다.

따라서 결과는 다음과 같다.

```text
결과: 15
결과: 5
```

### 핵심

> **함수 포인터를 매개변수로 사용하면 하나의 함수에서 전달받은 함수에 따라 서로 다른 작업을 수행할 수 있다.**


* 함수의 매개변수에 **void포인터**를 활용하는 예제 실행결과

## 설명

### 1. `void* ptr`

```c
void A(void* ptr)
```

- `void*`는 **모든 자료형의 주소를 저장할 수 있는 포인터**이다.
- 따라서 `int*`, `double*`, `char*` 등의 주소를 전달할 수 있다.

### 2. `A(&num)`

```c
A(&num);
```

- `&num`은 `num`의 **주소값**이다.
- 이 주소가 `void* ptr`에 전달된다.

### 3. `(int*)ptr`

```c
(int*)ptr
```

- `ptr`은 `void*`이므로 자료형이 정해져 있지 않다.
- 따라서 `int*`로 **형변환**한다.

### 4. `*(int*)ptr`

```c
*(int*)ptr
```

- `ptr`을 `int*`로 형변환한다.
- `*`를 사용하여 해당 주소에 저장된 값을 가져온다.
- 따라서 `num`의 값인 `10`을 가져온다.

### 5. `int num = 10.123`

```c
int num = 10;
```

- `num`은 `int`형

## 실행 결과

```text
10
```

## 핵심 정리

> `void*`는 모든 자료형의 주소를 저장할 수 있다.
>
> `void*`를 간접참조할 때는 **원래 자료형으로 형변환한 후 간접참조**해야 한다.
